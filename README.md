# 🔮 Voice of Oracle: Java GUI Personality Predictor

A desktop graphical user interface (GUI) application built with Java Swing. Originally titled **"Voice of Oracle"**, this application takes a user's birth date as input, calculates their astrological Zodiac sign, and displays a customized personality profile along with a corresponding visual avatar.

## 🎓 Academic Background

This repository showcases the second official project of my academic journey, marking my transition from console-based applications to event-driven, graphical desktop software. It was developed collaboratively as a group assignment.

* **Course:** CSE 2108 - Object-Oriented Programming Language II Sessional
* **Level:** Level 2, Term I
* **Type:** Group Project

## ✨ Features

* **Interactive GUI:** Built using Java Swing (`JFrame`, `JPanel`, `JComboBox`, `JButton`).
* **Event Handling:** Implements `ActionListener` and `ItemListener` to process user dropdown selections and button clicks dynamically.
* **Visual Integration:** Uses `ImageIcon` and `BorderLayout` to render specific Zodiac artwork based on the calculated result.
* **Input Validation:** Ensures users select both a month and a date before processing, triggering a `JOptionPane` error dialog if data is missing.

## 🛠️ Tech Stack

* **Language:** Java
* **Libraries:** `javax.swing.*`, `java.awt.*`
* **IDE/Environment:** NetBeans

## 🚀 How to Run

1. Clone this repository to your local machine.
2. Ensure you have the Java Development Kit (JDK) installed.
3. Open this project directly in **Apache NetBeans** (it contains the necessary `build.xml` and `nbproject` files).
4. Run the `VoiceOfOracleV3.java` file to launch the application.

*Note: All image assets (`.png`) must remain in the root directory for the application to render them correctly.*
